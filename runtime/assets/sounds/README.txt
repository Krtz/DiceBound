Dicebound sound-pack support (Beta 0.4.3)

Custom sound effects can be added later by placing files in assets/sounds/custom/ using one of these base names:
roll, step, hit, crit, coin, heal, lose, level, win, holy

Supported file extensions are tried in this order: .ogg, .mp3, .wav, .webm.
In the Options menu, switch Sound Pack to Custom to make the game try these files first.
If a custom file is missing or fails to play, Dicebound automatically falls back to the built-in synthesized effect.
