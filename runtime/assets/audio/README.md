# DiceBound audio assets

`audio/music/` is for packaged music, `audio/sfx/` for packaged effects, and `audio/custom/` is the runtime lookup location for optional custom overrides named `roll`, `step`, `hit`, `crit`, `coin`, `heal`, `lose`, `level`, `win`, or `holy` with `.ogg`, `.mp3`, `.wav`, or `.webm`.

Missing custom files intentionally fall back to DiceBound's built-in synthesized sound.
