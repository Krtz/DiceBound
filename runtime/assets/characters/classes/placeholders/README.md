# Class art placeholders

This folder documents class visuals that still use shared/duplicate/fallback art. Runtime class images belong in sibling `campsite/`, `battle/` and `markers/` folders using `<class-id>.png`.

Known visual debt is tracked by GitHub issue #13. In particular, some battle images are intentionally shared until replacement art exists. Do not put live replacement PNGs in this placeholder folder; put them in the correct context folder and update `ART_MAPPING.json`.
