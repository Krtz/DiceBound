## Beta 0.6.7.12

### Class art continuity
- Adds one canonical active-class presentation owner for HUD, combat portrait and Road marker artwork.
- Fresh runs and Board transitions render the selected class art immediately, before the first dice roll.
- Repeated HUD and movement refreshes reuse the same semantic image nodes instead of restoring legacy class emoji.
- Drains the old class portrait and Road-marker rendering helpers from `runtime/js/dicebound.js`; emoji is retained only as an actual asset-load fallback.

### Achievements
- Repairs **Fourth Road Conqueror** by reading the authoritative lifetime Board-clear ledger instead of the stale `board4Clears` counter.
- Moves **Fifth Road Conqueror** and **Two Fists Full of Dice** to the same canonical Board-clear achievement fact.
- Historical Board-clear counters remain readable only as a save-compatibility bridge for achievement evaluation.
- Hero Mastery prerequisite text now derives named prerequisites from canonical achievement/gate data instead of vague “listed achievement” wording.
- Locked secret prerequisites remain secret-safe.
- Adds explicit authored condition copy for the Invoker achievement conditions that previously fell through to generic text.

### Turtle
- Turtle now gains its existing one-Barrier Shell Wall reward on every even consecutive Guard: 2, 4, 6, 8, and so on.
- Shell Momentum's existing cap and temporary Guard-power scaling remain unchanged.
- The Barrier cadence uses an independent consecutive-Guard counter so an even Shell Momentum cap cannot accidentally award a Barrier every later Guard.
- Consuming Shell Momentum with the next basic attack resets the consecutive-Guard cadence exactly with the existing chain reset.

### Cleanup and validation
- Adds deterministic ownership coverage for active class art, including anti-return guards against the retired monolith renderers.
- Adds achievement-policy coverage for Board 4/5 facts, legacy-save reads, named prerequisites and secret-safe copy.
- Expands Turtle Guard coverage through Guards 1–6 and verifies the basic-attack reset.
- Preserves existing Guard ordering, RNG behavior, Shell Momentum scaling, class selection and combat action semantics outside the requested changes.
