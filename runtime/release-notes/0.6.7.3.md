# DiceBound Beta 0.6.7.3

## Road Dice ownership cleanup

- Fixed the 2d6 hard lock caused by invoking an already-resolved RNG number as a function.
- DiceboundRunDice now owns both 1d6 and 2d6 road rolls, Fate choice UI, roll controls, Long Stride and Titanstep roll behavior.
- Removed the old 1d6 implementation, Fate chooser state, duplicated dice faces and v2.5 rollDice replacement wrapper from dicebound.js.
- Primary button and keyboard rolling now delegate directly to the canonical Run Dice owner.
- Normalized lifetime roll accounting so every completed 1d6/2d6 road roll increments run and lifetime roll counters exactly once.
- Added deterministic coverage for 1d6/2d6, Fate, Long Stride, Titanstep, failure recovery and monolith anti-return ownership.
