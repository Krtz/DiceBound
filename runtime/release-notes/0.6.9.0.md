## Allied combat, Necromancer and authored asset expansion

Beta 0.6.9.0 is the feature release for DiceBound's first real player-side allied combatants.

Planned/shipping scope is tracked by #471:
- Combat-owned allied entity lifecycle, targetability, threat, healing, statuses and future persistence/control seams.
- Necromancer as the first targetable-summon class, with Grave Coil, Skeleton Warriors, Bone Shrapnel and Army of the Dead.
- Composable combat actions so classes, Powerups, Talents, gear and later controllable allies can add battle choices without hard-coded button ladders.
- Summon Career facts and the hidden “Nice.” achievement at 69 lifetime summons.
- Authored Necromancer/summon presentation and the audited interrupted Codex asset batch.

This file is intentionally updated as the active 0.6.9.0 implementation converges; PR #472 must not merge until #471's complete browser/Edge/native release gate is green.
