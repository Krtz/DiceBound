## Echo Crucible
- Build the permanent Echo Crucible on the Prestige Moon for **20 PP**.
- Sacrifice generated Legendary gear to learn its stable Legendary Effect forever; a new Effect teaches the Crucible, while a duplicate converts into exactly **1 Moon Metal**.
- Select one global Echo between runs. The selected Echo is locked into the run, shares the canonical Legendary-effect engine with equipped gear, and never double-applies the same semantic Effect.
- Class-specific Echoes remain selectable on any hero but clearly warn before an incompatible run and do nothing on incompatible classes.
- Sacrifice is guarded and persistence-safe: Artifact/authored Mythical gear is excluded, active Heirlooms must be removed first, and the physical item plus reward commit together.
