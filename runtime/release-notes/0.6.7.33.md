# DiceBound Beta 0.6.7.33

## Starfall, Quick Brew & asset cleanup

### Gameplay
- Sorcerer **Starfall** now restores exactly **33% of maximum Mana** once per use, through the authoritative Mana owner and clamped at max Mana.
- Starfall keeps its existing damage, Lifesteal/healing, elemental-proc and Powerup composition.
- Alchemist **Quick Brew** is now explicitly **Unique**: once acquired, it cannot be offered again during the same run and becomes eligible again on the next run.

### Asset architecture
- Retired all ten historical runtime compatibility-mirror roots tracked by #31.
- Current runtime/class/pet/enemy/camp/board/equipment/Powerup presentation continues through semantic asset homes.
- The asset validator now rejects both returned legacy directories and any live runtime pointer that tries to use a retired compatibility prefix.

### Validation
- Starfall coverage locks exact 33% max-Mana restoration, single resolution and max-Mana clamping.
- Powerup registry coverage locks Quick Brew to the existing per-run unique contract.
- Asset architecture validation locks compatibility-root count at zero and prevents shadow paths from returning.
