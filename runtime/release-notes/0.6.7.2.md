# DiceBound Beta 0.6.7.2

## Gold policy regression fix

- Restored Heavy Purse to the shared level-scaled Gold baseline instead of its stale flat 100-base implementation.
- Heavy Purse now uses 70% of `50 + 20 × Adventurer Level`, then applies the normal Gold modifier exactly once; its live description reports the same payout it will actually grant.
- Removed the old Beta 0.6.4.3 global Powerup-registry interception bridge. Shared reward numbers stay in EventRewards while the Powerup registry owns Heavy Purse behavior through an explicit runtime service port.
- Added direct live-registry regression coverage at Adventurer Levels 1 and 10, including a non-zero Gold bonus so double-modifier regressions are caught.
- No other Powerup balance, reward tables, Hidden Purse talent values, RNG, save/checkpoint or combat behavior are intentionally changed.
