## Character Gear rich-detail + enemy battle-art scale hotfix

### Fixed
- Character → Gear now owns the actual player-visible equipment detail popover instead of relying on the generic root text-tooltip path.
- Hover/focus resolves the equipped item from the rendered slot key at display time, so old/current items with generic presentation fields still show the real semantic equipment identity.
- Rich Gear detail shows equipment art, real item name, rarity + actual slot, authored bonuses, Intrinsic, elemental detail, Unique/Legendary effect and Impossible Road set information when present.
- The accessible slot label continues to expose the same authoritative semantic detail.
- The generic root tooltip is suppressed while Character Gear owns the hover, avoiding the generic `Equipment · RARITY` card seen in live 0.6.7.30 playtest.

### Battle presentation
- Skeleton, Cultist, Orc and Bandit battle artwork is rendered 15% larger.
- Scaling is applied to the artwork node from a center-bottom origin rather than the animated stage sprite, so enemy lunge timing/transform ownership is unchanged.
- Enemy stats, targeting, RNG, hit logic and board artwork are unchanged.

### Regression coverage
- Static Character UI coverage requires the dedicated rich detail owner and actual rendered slot identity.
- Real Edge coverage opens the same rich Character Gear popover the player sees and verifies semantic name, rarity/slot, authored stats, Intrinsic, art and accessible copy.
- The historical Impossible Road contamination regression now verifies the rich player-visible popover instead of the unrelated root tooltip.
- Combat presentation coverage locks semantic enemy IDs and the exact 1.15 scale for Skeleton/Cultist/Orc/Bandit.
