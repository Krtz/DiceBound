## Beta 0.6.7.18 — Combat & Career Polish

- Hardened **Floating Combat Numbers** after real-playtest reports of intermittent visibility. Floating values now begin their visible lifetime only after a browser paint, re-anchor to the settled semantic recipient after combat reflow, carry an explicit pack index alongside the resolved enemy object, and retain the persistent Options toggle.
- Added a real Edge regression that proves floating values are visible, target the correct member of an enemy pack, remain geometrically anchored after paint, and disappear when **Floating Combat Numbers** is disabled.
- Rebuilt the top of the battle scene into **target chooser → static parallel Player/Enemy HP HUD → battlefield models**. HP/status UI no longer rides with differently-sized character art.
- Grounded player and enemy art by making the model the bottom-most fighter element; identity/companion/weakness copy now sits above the model instead of consuming ground space below it.
- Retuned **Echo Strike presentation**: the first Echo uses that class's ordinary attack cadence so ≤100% Echo reads like two attacks. Additional guaranteed Echoes then accelerate gradually to a readable floor without changing Echo count, damage, RNG or action order.
- Fixed **Career** presentation against real persisted saves. Career now shows a useful persisted snapshot, includes lifetime **Damage Taken**, migrates only trustworthy legacy counters at the load/import boundary, and keeps bounded Run History honest instead of inventing historical runs.
- Strengthened the Career Edge test to save, reload, acknowledge legitimate Camp overlays, open Career through the real Camp hit target and verify non-zero Overview, Enemy Ledger and Run History values.
- Moved the **Hell Mode** Camp toggle 10 scene-percentage points to the right.
- Simplified **Heavy Purse** copy to show the exact resolved reward — **Gain X gold now.** — instead of exposing internal base/formula bookkeeping. Reward math itself remains on the current scaling policy.
- Cleaned up **Pokémon Trainer** unlock ownership: the working all-pets-level-10 + any-difficulty Beastmaster Board 5 rule remains canonical, while the stale Nightmare-only compatibility path/state is retired.
- Added the vague Beastmaster achievement **A Bigger Roster** for clearing Board 5, hinting that the menagerie has more depth without spelling out the Pokémon Trainer recipe.
- Reworked **Twenty-Sider** combat feedback from several duplicate announcements into one resolved message containing the roll, outcome and concrete action effect, plus one matching Battle History entry. D20 RNG consumption and outcome mechanics are unchanged.
