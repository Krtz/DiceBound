## Debug Bundle + save health

### Added
- Options now includes **Debug bundle & save health**.
- Save health shows the current primary-save age/validity, valid backup count + newest backup age, current save schema and runtime build identity.
- **Export Debug Bundle (.zip)** creates a real native ZIP under DiceBound's app-data debug-bundles folder and reveals the generated file in Explorer.
- The ZIP includes:
  - native/startup + forwarded runtime log;
  - runtime diagnostic metadata;
  - native wrapper/WebView2 bootstrap mode;
  - relevant app-data/save/runtime-cache/game/WebView2 paths;
  - committed runtime build-info/build-manifest metadata;
  - exact release-source Git commit provenance when the release is built by CI.

### Privacy
- Player save/progression files are **excluded by default**.
- Options exposes an explicit unchecked **Include save/progression files in this export** consent checkbox.
- The consent is per-export, is never persisted, and resets to off after a successful export.
- Save contents are copied only by the native ZIP owner after explicit opt-in; the runtime diagnostic JSON never embeds save meta/checkpoint payloads even when opted in.
- Browser builds report save health where available but disable native ZIP export.

### Ownership
- `DiceboundSave` owns non-mutating save-health inspection.
- `runtime/js/core/debug-bundle.js` owns privacy-safe diagnostic report composition.
- `DiceboundRuntime` exposes that focused owner to Options.
- Platform/native WebView2 owns filesystem, log collection, release provenance and ZIP creation.
- Options owns presentation/consent only.

### Validation
- deterministic Save/Debug tests prove health inspection does not rewrite saves and default reports cannot contain fake progression secrets;
- native source contract proves save-file ZIP entries exist only inside the explicit `IncludeSave` branch;
- Runtime peer/facade/load-graph tests lock the new focused owner;
- Options tests lock unchecked-by-default consent and one-export reset semantics.
