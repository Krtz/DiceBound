## Beta 0.6.7.8

This release repairs two reported Legendary-effect paths and adjusts the Campsite difficulty-control layout.

### Throne of Venom
- Fixes the extracted Powerup registry's stale dependency on composition-local class data.
- Poison-tag detection now travels through the canonical Powerup runtime-service boundary.
- Preserves the intended effect: +50% Poison Chance, +10% Lifesteal, +40 Poison-damage points for poison-tagged classes, and +20 for other classes.
- Adds direct regression coverage for poison-tagged and non-poison classes and prevents a global CLASSES dependency from returning.

### Hoarder's Arsenal
- Verified the complete equipped-effect path and the documented 500-gold thresholds instead of changing working combat math.
- Deterministic coverage now proves 499 / 500 / 1000 / 1500 gold behavior on both basic and Echo strikes, plus stable effect-ID aggregation, save/checkpoint-style serialization, and gear replacement.
- The Legendary equipment description now shows the live `floor(gold / 500)` bonus at the player's current gold, making the effect observable despite ordinary strike variance and mitigation.
- Hoarder's Arsenal combat math is intentionally unchanged in this release; the patch makes the verified effect visible and locks its thresholds with regression coverage.

### Campsite
- Moves the Nightmare control 10 percentage points downward.
- Moves the Hell control 50 percentage points left, including its active volcano representation.

### Validation
- Focused Powerup, Items, Combat-strike, and Camp owner tests cover the touched responsibility slices.
- Normal repository, Edge/browser, native WebView2, architecture, asset, and release gates remain required before shipping.
