## Adaptive Board HUD

- Gear hover/focus detail now falls back from generic `Equipment` names to the canonical semantic item identity.
- Modern Gear detail always tries the live total equipment bonuses when composed copy is empty, so intrinsic-only gear still shows real stats.
- Gear tooltip copy is split into readable identity / rarity+slot / stat lines.
- Roomy HUDs use measured Character, Companion and Adventure Log geometry instead of relying only on viewport breakpoints.
- When Character is substantially taller than Companion, Companion packs beside it and Adventure Log fills the space directly underneath.
- When that packing would not fit cleanly, Adventure Log falls back beneath both columns.
- Stats/Gear tab switches and live resizing trigger a fresh packing decision.
- Side Travel controls now use a width-aware compact/full presentation.
- Narrow side rails show a single-line **Roll** button instead of wrapping **Roll the dice** over several lines.
- Wider side rails restore the full **Roll the dice** wording and a roomier Road/Guardian layout.
- The Board remains square and keeps the 0.6.7.26 side-control space gains.
- No save-schema, gameplay, RNG, Board-generation, movement, item-mutation or checkpoint change.
