## Beta 0.6.7.17 — Floating Combat Numbers

- Added semantic floating combat text through the existing **Combat → Combat View → VFX** presentation boundary.
- Damage now appears over the **actual resolved enemy target**, including pack members, Echo/multi-hit strikes, elemental damage, Poison, Thorns/reflection and other secondary damage that already routes through canonical damage resolution.
- Incoming player damage now distinguishes **Energy Shield absorption** from real HP loss with separate readable values.
- Combat healing and net Energy Shield gains now use the same presentation system without changing their underlying resolution.
- Merchant barriers show an explicit **Barrier** result instead of relying on color-only feedback.
- Rapid values use per-target lanes so short bursts remain readable instead of drawing every number on the same pixel.
- Floating text is body-mounted and bounded, so lethal-hit re-renders do not destroy the number mid-animation and combat transitions clean up all pending text/timers.
- Added `prefers-reduced-motion` handling that keeps the values readable while removing the travel animation.
- Added **Options → Floating Combat Numbers**. The setting is persistent, defaults **On** for both new and existing saves, and disables only the supplemental floating overlay.
- Added deterministic pack-target, rapid-lane, damage/absorb, healing/shield, toggle, reduced-motion and cleanup contracts.
