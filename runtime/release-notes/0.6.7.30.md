## Character Gear detail hotfix

### Fixed
- Character Gear no longer leaks literal `<img ...>` markup from old saved Hat icons.
- Hover/focus detail now stays on the real equipment identity, rarity, slot, bonuses, unique effect and set information.
- Impossible Road and other authored special gear now use the modern equipment model underneath: a deterministic, slot-valid `equipmentId` supplies reusable art and a real Intrinsic while the authored Artifact/Mythical/Omega name, effect and set layer remain intact.
- Existing special gear without an `equipmentId` is migrated before equip-stat application, so its Intrinsic reaches gameplay rather than becoming display-only metadata.
- Current-schema careers with Hat icons contaminated by the retired Beta 0.4.3 presentation bridge are repaired to safe scalar icon data.
- Impossible Road Crown, Kratz Headphones and The Devil's Horns recover their semantic fallback icons when affected.

### Cleanup
- Deletes the obsolete `beta043RefreshEquipmentArt()` path that wrote HTML markup into equipment model fields.
- Current semantic Equipment/Assets/UI owners remain responsible for gear presentation and modern base-identity selection; the retired special-gear parallel path no longer bypasses them.
- Character Gear, Classic Equipment, Heirloom Vault, loot cards and end-of-run gear surfaces all use the same safe icon/detail path.

### Validation
- Deterministic icon-safety coverage locks markup detection, repair and idempotence.
- Character-panel ownership tests reject return of the retired Hat HTML mutation.
- Artifact factory coverage requires every Impossible Road slot to carry a valid modern `equipmentId` with a non-empty Intrinsic without consuming additional gameplay RNG.
- Real Edge coverage reproduces the 0.6.7.29 screenshot failure with a contaminated special Hat and requires canonical Crown detail, modern equipment art, live Intrinsic stat application and zero HTML leakage.

No gameplay RNG, balance, item-stat, save-schema or equipment-slot changes.

Fixes #455.
