# Beta 0.6.9.2 — Enemy summon targeting hotfix

- Fix live enemy-turn composition so ordinary enemies can actually select living, targetable allied summons instead of silently falling back to the hero every time.
- Move the existing player-side target and allied-damage routes into the authoritative combat turn resolver and make both callbacks mandatory, preventing this wiring regression from failing silently again.
- Preserve the shipped weighted default: ordinary enemies use the existing 50/50 hero-vs-summon bucket, with summon threat weights resolving within the summon half.
- Preserve existing Guardian policy: Guardian attacks/specials remain hero-focused; this hotfix does not make an unrelated boss-balance change.
- Add deterministic unit coverage for enemy-to-summon damage and a real Edge regression proving a seeded ordinary enemy damages the Skeleton while leaving the Necromancer untouched.
