# DiceBound Beta 0.6.7.14

## Ordinary Demon identity — #158
- The ordinary `Devil` family is now canonically `demon` / **Demon**.
- **The Pale Devil** remains a distinct special `pale-devil` identity and is unchanged.
- Ordinary Demon Fire behavior now keys from the stable semantic family ID instead of parsing the display name.
- Existing Board 1–6 ordinary battle art is preserved through the new Demon identity; legacy physical `devil-board-*.png` filenames remain implementation detail.
- The existing `demon.png` road marker remains canonical.

## Regression protection
- Frozen enemy-scaling characterization keeps exact numeric stats and RNG behavior across the identity migration.
- Focused policy, marker and battle-art tests require canonical Demon identity while allowing legacy ordinary Devil labels only as art-resolution compatibility input.
- No spawn rates, elemental odds, weakness behavior, balance values or save schema change in this slice.

## Scope
- This release completes only the focused ordinary Devil → Demon semantic migration.
- The broader bounded elemental-name composer remains open on #158 for later design/work.
