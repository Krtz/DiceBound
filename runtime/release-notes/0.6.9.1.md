## Necromancer turn-lock and enemy presentation hotfixes

Beta 0.6.9.1 fixes issues found immediately after the 0.6.9.0 allied-combat release.

- Fix the Necromancer Summon Skeleton path so a post-summon response failure cannot leave combat permanently locked.
- Add a real Edge interaction regression that clicks Summon Skeleton and requires the full allied / companion / enemy response to return control to the player.
- Preserve visible ordinary-enemy growth across Boards even when later encounters use multi-enemy packs.
- Restore miniboss visual presence with a Board-scaled guardian hierarchy while keeping final guardians larger.
- Lock Board-transition stat invariants so Luck and Lifesteal are never reduced simply by advancing a Board, including Nightmare runs.
