# DiceBound Beta 0.6.7.34

## Player copy, live tooltips, Deadeye & Invoke

### Player-facing copy
- Powerup presentation resolves descriptions through the canonical Powerup descriptor instead of snapshotting raw `.desc` text.
- Heavy Purse therefore follows the live Gold reward calculation wherever its description is shown.
- Mystic offers use canonical Powerup descriptions, no longer reveal the internal rarity table, and truthfully describe the authored maximum-HP cost and actual offered rarity.
- Combat Ultimate tooltips use the effective Ultimate descriptor; Unstable Ultimate reads threshold/damage values from the Legendary-effect owner.
- Crit probability labels use **Crit Chance** where the text names the stat.
- Roadkeeper's Guide removes internal gear-budget numbers and stale worked examples that duplicated mechanics.
- the in-app version subtitle is player-facing rather than an implementation changelog.

### Combat presentation
- Deadeye Volley and other dedicated authored player proc effects no longer request the legacy emoji element animation before their dedicated VFX.
- gameplay, proc RNG and damage are unchanged.

### Invoke / Unstable Ultimate
- Invoke is an Ultimate action for Unstable Ultimate.
- the Legendary's authoritative charge threshold unlocks Invoke at the same charge as other Ultimates.
- its authoritative damage multiplier applies exactly once to damaging Invoke formulae; utility-only formula durations/barriers remain authored values.
