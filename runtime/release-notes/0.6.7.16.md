## Beta 0.6.7.16 — Career History

- Added a dedicated **Career** destination at Camp with **Overview**, **Enemy Ledger** and **Run History** views.
- Added bounded **30-run history** committed exactly once at terminal settlement. Records keep semantic class/mode/companion identity, Board reached, outcome, final level/Gold/Legacy XP, effective stats, equipment, Powerups, version and authoritative run RNG seed.
- Added an authoritative lifetime Career telemetry owner behind `DiceboundProgression`, preserving trustworthy existing counters while allowing genuinely new counters to begin with this release rather than inventing old history.
- Added a semantic enemy defeat ledger keyed by stable enemy IDs, so generated epithets and Board presentation never fragment one enemy family into fake categories.
- Added lifetime **largest hit, Critical strikes, Echo strikes, elemental procs, abandoned runs and class run counts**.
- Career Overview shows the highest Board cleared per difficulty for each class instead of redundant lower-board clear rows.
- Removed the old duplicate Career Stats presentation from Info; Info is again focused on rules, elements and save tools.
- Fixed fresh-run terminal state so every new run explicitly resets finalization before settlement/history tracking.
- Fixed lifetime Dice Roll accounting so completed runs are not counted once during play and then a second time at settlement.
- Moved touched lifetime-stat ownership out of `dicebound.js`: Combat, Items and Run now report resolved semantic facts through Progression rather than mutating `meta.stats` directly.
- Added deterministic Career-domain tests, anti-return ownership contracts and real Edge pointer tests for the Camp Career destination.
