## Beta 0.6.7.7

This release combines three player-facing responsibility cleanups: Luck-driven rarity, enemy attack presentation, and Echo Strike pacing.

### Luck → rarity
- Audited the full ordinary Luck → rarity path instead of patching only one reward source.
- Poor/Common suppression now has one canonical policy: it begins at 100 displayed Luck, ramps continuously through 125/150/175, and reaches a deterministic Uncommon floor at 200 Luck.
- Ordinary generated gear, ordinary Powerup choices, miniboss Powerup rewards, and guardian/miniboss/boss generated gear all consume that same policy.
- Existing reward-source rarity curves remain intact above the suppressed low tiers.
- Luck suppression reuses each source's existing rarity draw; it does not add gameplay RNG draws.
- Added seeded 20,000-roll distribution coverage at 0/25/50/100/125/150/175/200/500 Luck plus exact guardian/Powerup boundary tests.

### Enemy attack presentation
- Combat Turn Resolution now emits semantic attacker/attack/hit/outcome facts for incoming attacks.
- Combat View / Combat Presentation own a generic enemy attack fallback animation.
- The actual attacking pack member animates, including ordinary hits, multi-hit attacks, blocked/dodged attempts, guardian specials, and Wolf Echo.
- The semantic pipeline is ready for later per-monster/per-attack art without adding monster-name presentation branches to combat orchestration.

### Echo Strike pacing
- Removed the old global fast-Echo delay cap that could squash unrelated strike delays down to single-digit milliseconds.
- Ordinary attacks no longer speed up merely because the build has high Echo.
- Echo presentation now owns an explicit cadence: 180 ms for the first Echo, 3 ms faster per additional Echo, with a 60 ms readability floor.
- Echo damage, count, targeting, Crit eligibility, proc order, and gameplay RNG are intentionally unchanged.

### Architecture / validation
- Player attack motion now routes through Combat View instead of being implemented in the composition monolith.
- The retired global Echo-cap plumbing is removed from strike resolution and composition.
- Full deterministic/browser source tests preserve the released combat gameplay/state/event/RNG oracles while covering the new presentation and Luck policies.
