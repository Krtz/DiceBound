# Back gear TODO

Future-slot/backburner design sheet for issue #83.

Back is **not currently a DiceBound runtime slot**. This file exists so capes, cloaks, wings, backpacks, banners, back-mounted quivers and other rear-worn equipment have one slot-centric home. Adding a runtime Back slot still requires an explicit design/implementation decision.

Source-specific RuneScape / Path of Exile / Diablo names are prototype/reference language only and should be renamed/originalized under #93 before a public/commercial release where appropriate.
