# RuneScape reference-pool policy

For DiceBound gear inspiration, RuneScape/OSRS source material is intentionally **uncurated**.

Keep reference candidates even when they are:

- quest-only;
- joke/fun weapons;
- holiday/event rewards;
- discontinued;
- obsolete;
- mechanically useless;
- ceremonial;
- toys/props;
- tools that happen to be wieldable;
- banners/trophies;
- strange one-off weapon forms.

The purpose of the source-inspired files is not to define the exact shipping loot table. They are a large inspiration library we can pull from whenever something feels fun, cool, weird or mechanically useful.

Do not remove an item from the reference pool because DiceBound probably will not implement it. Promotion into the normal `geartodo/<slot>.md` files is the point where we decide whether it becomes an actual DiceBound base identity.

Source-specific names remain prototype/reference language and should be reviewed under #93 before any public/commercial release.
