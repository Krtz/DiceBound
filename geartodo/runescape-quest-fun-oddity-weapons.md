# RuneScape quest, fun, holiday and oddity weapon reference pool

Working reference catalogue for issue #83.

## Purpose

This file is intentionally **uncurated**.

The rule is now:

> If RuneScape or Old School RuneScape ever let you wield something funny, quest-specific, seasonal, ceremonial, bizarre, obsolete, impractical, iconic or just plain stupid, it is useful DiceBound reference material.

This is **not** a promise to implement every item. It is a museum / idea hoard we can raid whenever something looks fun enough to become a DiceBound equipment base, Legendary effect, Artifact, achievement reward, class item, event prop or secret loot drop.

Do not prune an entry merely because it is weak, joke-only, obsolete, holiday-limited or mechanically useless in its source game. Those are often exactly the interesting ones for DiceBound.

Names that are strongly source-specific are reference language only and belong in #93 before any public/commercial release.

Cool is still reserved for explicitly special DiceBound gear; being a funny source item does not automatically grant the Cool stat.

# 7. Joke weapon design lessons worth stealing

The useful idea is not merely the names. RuneScape repeatedly treats **objects with strong identity** as valid wieldables even when their combat purpose is ridiculous.

DiceBound should embrace the same principle.

Possible mechanical translations:

- Rubber Chicken -> weak Attack, strange Crit/Echo/Donut interaction
- Undead Chicken -> Lifesteal / Void / summon weirdness
- Flowers -> Nature proc + Dodge, tiny Attack
- Easter Carrot / Carrot Sword -> Nature + HP / Potion Healing
- Giant's Hand -> absurd Thorns / heavy Attack
- Barrelchest Anchor -> enormous Attack + Defense, brutal Dodge penalty
- Magic Secateurs -> Nature proc / Potion Healing / Crit
- Cattleprod -> Electric proc
- Frying Pan -> Thorns + Metal proc
- Rolling Pin -> Donut proc
- Stale Baguette -> huge Thorns, tiny Attack, possibly inexplicably high rarity
- Cursed Banana -> Confusion / Dodge / Luck
- Birthday Balloons -> Dodge / Echo / Luck
- Dragon Candle Dagger -> Fire proc + Crit
- Egg on a Fork -> Donut / Nature / extremely stupid Echo interaction
- Chick-Axe -> Crit + Nature
- Hook-a-duck Flail -> Luck + Echo
- Rat Pole -> Poison / Nature / pet weirdness
- Severed Leg -> Lifesteal / HP / horror-comedy
- Skeleton Lantern -> Void / Light contradiction
- Giant Present -> Gold Gain / random battle-start gift effect
- Crate of Books -> Defense + Mana, enormous weight

These are **idea directions**, not locked balance.

# 8. Reference-pool policy going forward

When we discover another RuneScape/OSRS weapon or wieldable oddity:

1. add it here even if it looks useless;
2. do not worry whether DiceBound will ever implement it;
3. if it inspires us, promote it into the normal `geartodo` slot file;
4. give the promoted DiceBound item its own identity/intrinsic/art direction;
5. rename/originalise source-specific expression later if public release requires it.

The goal is **maximum inspiration coverage, not catalogue purity**.
